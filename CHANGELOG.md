# Changelog

## 0.1.0-alpha.1 — 2026-11-25

### Added
- First Windows x64 installer and portable prerelease, Authenticode-signed with a self-signed test publisher certificate.
- Installer prerelease terms and optional launch at Windows sign-in.
- Settings update panel with manual checks, opt-in background checks/downloads, GitHub SHA-256 verification, and explicit installation.
- Device inventory, network discovery, monitoring, embedded SSH/local terminals, encrypted local accounts, backups, and mobile transfer codes.

### Changed
- Project license is now Apache 2.0. Third-party component licenses remain unchanged.
